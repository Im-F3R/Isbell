# Isbell Centro Estético

Sitio web estático (HTML, CSS y JS sin dependencias).

- `index.html` — contenido de la página
- `styles.css` — estilos
- `script.js` — menú móvil, filtros de servicios, reservas por WhatsApp

Para verlo, abre `index.html` en el navegador. Se puede publicar gratis en GitHub Pages, Netlify o Vercel.
